# avl-socio-torcedor
Cadastro de sócios-torcedores indexado por Árvore AVL em C: inserção com rotações, busca, remoção, listagem por faixa de ID e comparação de desempenho BST × AVL. Trabalho de Estrutura de Dados II (PUC Goiás).  Topics: c, avl-tree, data-structures, binary-search-tree, estrutura-de-dados, puc-goias
